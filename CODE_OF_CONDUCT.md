# Don't be a dick

That is the whole policy. In practice it means:

- Be kind. Assume good faith, and remember there is a person on the other end.
- Keep it about the work. Criticise code and ideas, not people.
- No harassment, no slurs, no personal attacks, no sharing anyone's private information. Anywhere the project is discussed.
- If you are wrong, say so and move on. Everyone is sometimes.

If someone is being a dick to you here, email me@vicnicius.com. I read it, I keep it private, and I act on it, up to removing people from the project.
